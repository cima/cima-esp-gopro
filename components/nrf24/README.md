# nRF24L01 Controller

A high level C++ object wrapper of [MIRF for ESP-IDF](https://github.com/nopnop2002/esp-idf-mirf) for (nRF24L01)[https://www.laskakit.cz/bezdratovy-modul-nrf24l01p--pa--lna-2-4ghz/] to fit more in my style project.

The mentioned repository is required as a component so it is best to check it out side by side with this repository.
